# 🚨 QUICK FIX - Error 404 Vercel

## Masalah
```
404: NOT_FOUND
```

## Solusi Tercepat (5 Menit)

### 1. Login Vercel
→ https://vercel.com

### 2. Pilih Project
→ Klik project "akademi-profesional-indonesia"

### 3. Settings
→ Tab "Settings" → "Build & Development Settings"

### 4. Edit Root Directory
→ Klik "Edit" pada "Root Directory"
→ Ketik: `akademi-profesional-indonesia`
→ Klik "Save"

### 5. Redeploy
→ Tab "Deployments"
→ Klik "..." pada deployment terakhir
→ Pilih "Redeploy"

### 6. Done! ✅
→ Tunggu 2-3 menit
→ Klik "Visit" untuk cek website
